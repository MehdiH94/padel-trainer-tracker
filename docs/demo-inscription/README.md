# Démo Padel Boost : créer son compte joueur et installer l'application

Images au format téléphone (iPhone : 1170 × 1992 px ; Android : 1236 × 2517 px).
Le rond orange montre où toucher. Données fictives : Yassine Ben Salah.
Durée conseillée : 2 à 3 s par image, 1 s pour les images de saisie (04, 07, 16, 19).

| Images | Voix off |
|---|---|
| 01 | Ouvrez padel-boost.net sur votre téléphone, puis touchez « Joueur ? Créer mon compte ». |
| 02 | Le formulaire d'inscription s'ouvre. Il ne prend qu'une minute. |
| 03 – 05 | Écrivez votre nom complet. |
| 06 – 08 | Puis votre numéro de téléphone. |
| 09 – 10 | Choisissez votre niveau de padel. |
| 11 – 12 | Dites si vous êtes droitier ou gaucher, et de quel côté vous jouez. |
| 13 – 14 | Choisissez vos objectifs : votre coach les verra pour adapter ses entraînements. |
| 15 – 17 | Indiquez votre adresse e-mail. |
| 18 – 20 | Et choisissez un mot de passe. |
| 21 | Touchez « Créer mon compte ». |
| 22 | C'est fait ! Ouvrez le lien reçu par e-mail pour confirmer votre adresse. Votre compte est ensuite validé, et vous pouvez réserver vos séances. |
| 23 | Pour l'avoir toujours sous la main, installez Padel Boost sur votre écran d'accueil. |
| 25 | Sur iPhone, dans Safari, touchez le bouton Partager… |
| 26 | …puis « Sur l'écran d'accueil »… |
| 27 | …et « Ajouter ». |
| 28 | Padel Boost est sur votre écran d'accueil, comme une application. |
| 24 | Sur Android, touchez simplement « Installer » dans l'application… |
| 29 – 30 | …ou bien, dans Chrome, ouvrez le menu (les trois points) et choisissez « Installer l'application ». |
| 31 | Confirmez avec « Installer ». |
| 32 | Et voilà : Padel Boost s'ouvre d'un geste. Bon padel ! |

Remarques :
- 01 à 24 sont de vraies captures de l'application ; 25 à 32 sont des schémas simplifiés des menus de Safari et de Chrome (leur apparence exacte varie selon le téléphone).
- Ordre conseillé pour le montage : 01 → 23, puis 25 → 28 (iPhone), puis 24, 29 → 32 (Android).
